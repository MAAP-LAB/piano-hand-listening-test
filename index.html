※ 미리보기 버전입니다. 아직 응답하지 마세요. (Preview only — please do not submit ratings yet.)
안내 (약 25분, 헤드폰 필수)
  1. 각 문항에는 목표 손(왼손 또는 오른손)이 표시됩니다.
  2. 위쪽 회색 상자의 원본 녹음과 가이드를 먼저 들으세요. 가이드는 목표 손이 치는 음만 MIDI로 합성한 소리입니다. 음색은 다르니 어떤 음이 목표 손인지를 아는 데만 쓰세요. (일부 문항에는 가이드 대신 정답(Reference)이 주어집니다.)
  3. 아래 무라벨 A, B, C… 를 모두 듣고 0–100점으로 평가하세요: 목표 손 소리만 깨끗하고 자연스럽게 들릴수록 높게, 다른 손 소리가 섞이거나 소리가 망가져 있을수록 낮게.
  4. 모든 클립을 한 번 이상 재생하고 모든 점수를 정해야 다음으로 넘어갈 수 있습니다. 진행 상황은 이 브라우저에 자동 저장됩니다.
  5. 끝나면 Export로 결과 파일을 내려받아 보내주세요.
Each trial names a target hand. Rate each unlabelled clip 0–100: higher = only the target hand, clean and natural.
